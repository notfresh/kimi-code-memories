# 编号规则 —— kimi-code-memories
# 最后更新：2026-09-30（郑旭口述）

## 1. 适用范围
本规则只针对主 Layer TOML 文件（如 Layer-longlife.toml）。
详情文件 Layer-*.toml.detail.toml 走独立处理流程，不在本规则范围内。

## 2. 字段定义
- 字段名：number
- 类型：整数（int）
- 位置：与 id 同级，非 id 替代
- 用途：对话/笔记中口语引用「第几条」的短锚点

## 3. 编号方式
- 全仓唯一递增，从 1 开始
- 新节点追加在文件末尾时，取当前最大 number + 1
- 严禁跳号、重复、回填历史节点改号

## 4. 注释规范
- 每个节点头部注释 `# ── 条目 N: ... ──` 中的 N 必须与该节点的 number 字段值一致
- 中间插入新节点时，后续条目的注释标题同步更新

## 5. 格式约定
- `number = N` 后接 `  # id.字符串`，方便肉眼对应
- number 与 id 在同一行注释中成对出现

## 6. 与 id 的关系
- id 是机器字符串（机器解析、跨仓唯一、不可改）
- number 是口语编号（人引用、当前仓内、谨慎新增）
- 两者同级、非唯一关系，number 不替代 id
